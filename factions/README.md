# 势力总表

世界规则和意识形态标签见 [worldbuilding.md](../worldbuilding.md)。  
一个势力一个文件。  

## 三类势力

- 意识形态势力：有明确的武学观，想建立某种秩序。  
- 运转型势力：维持武学社会日常运转的行业。  
- 零散势力：没有统一组织，散在各地。
